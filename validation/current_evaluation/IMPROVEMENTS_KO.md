# 분석 엔진 개선 결과 — 2026-10-21

기존 지원 기능의 회귀 테스트를 유지하면서 오연결 방지와 일부 누락 패턴을 개선했다.
원본 분석 대상 코드는 실행하지 않는다. VS Code 확장은 0.2.0으로 패키징했다.

## 변경

- `tokenize.open`으로 인코딩 선언 및 UTF-8 BOM을 처리한다.
- 알 수 없는 데코레이터를 가진 함수·클래스와 감지된 메서드 변경에 대해 원래 정의의
  호출 간선과 반환값 추론을 유보한다. 직접 클래스 속성 대입·삭제,
  단순 클래스 별칭, 명시적 setattr/delattr를 검사한다.
- 내부 async 함수 호출은 coroutine 값으로 보관하고 await 시점에 본문·반환값·필드 변경을
  분석한다. await하지 않은 호출 및 async generator를 일반 반환 객체로 간주하지 않는다.
- 최대 32개 원소의 작은 리스트·튜플·딕셔너리에 리터럴 키/인덱스 접근을 지원한다.
  음수 시퀀스 인덱스와 중복 딕셔너리 키도 처리한다.
  변경·별칭·외부 전달 시 원소와 도달 가능한 객체 필드를 보수적으로 무효화한다.
  루프도 변경 전의 원소 스냅샷 대신 현재 컬렉션 heap을 참고한다.
- match의 분기별 환경과 반환값을 병합한다. 캡처 이름의 가림과 무일치 경로를 반영한다.
  패턴의 실제 매칭 가능성을 정밀하게 판별하는 기능은 아니다.
- 추적한 객체의 환경이 구형 문법 기반 flow 스냅샷보다 우선한다.
  이를 통해 `if False`의 불가능한 후보가 다시 추가되지 않는다.
- finally가 명시적인 마지막 return으로 끝나면 pending 반환값과 heap 스냅샷을 대체한다.

## 검증

기존 267개 + 신규 회귀 테스트 42개 = **309개 모두 통과**.
새 테스트는 정상 패턴 외에 컬렉션 변경·외부 전달·캡처 가림·async generator 등
확신해서는 안 되는 사례와, 기존 분석기로 잘못 되돌아가는 사례를 포함한다.

개선 전후 **동일한 소스·기대 대상**의 합성 focus-call 사례 22개를 비교했다.

| 지표 | 개선 전 | 개선 후 |
|---|---:|---:|
| 대상 집합 정확 일치 | 9/22 | 15/22 |
| 올바른 대상 간선 TP | 10 | 15 |
| 잘못 추가한 대상 간선 FP | 5 | 1 |
| 놓친 대상 간선 FN | 11 | 6 |
| 해당 표본 Precision | 66.7% | 93.8% |
| 해당 표본 Recall | 47.6% | 71.4% |

이 표본은 개발과 검증에 사용한 경계 사례로, 독립적인 실전 정확도나 일반화 성능이 아니다.
데코레이터·메서드 교체의 두 오연결은 UNKNOWN으로 바꿨다. 실제 교체 대상은 여전히 놓치므로
두 사례는 정확 일치로 계산하지 않았다. 정답 기대치를 낮추지 않았다.

파싱 보조 사례에서는 UTF-8 및 Latin-1 선언 파일 모두 읽고,
의도적으로 잘못 만든 문법 파일만 오류로 보고한다.

VSIX 검증:

- ZIP 무결성 통과.
- 포함된 모든 Python 파일이 현재 체크아웃과 바이트 단위로 일치.
- 임시 폴더에 추출한 VSIX 엔진을 Python isolated 모드로 실행해
  22개 focus 호출의 대상이 체크아웃의 결과와 일치하는 것을 확인.
- VS Code GUI 실행은 이 환경에 VS Code/Node.js가 없어 수행하지 못함.

## 남은 범위

- getattr·property·with 반환 객체·클로저: 평가한 사례는 UNKNOWN으로 남는다.
- 데코레이터 교체·클래스 메서드 변경: 정확한 새 대상 대신 UNKNOWN으로 남는다.
- 반복문은 고정점 분석이 아니므로 평가 사례에서 불필요한 후보 간선 하나가 남는다.
- finally의 복잡한 조건부 return/raise 조합과 패턴 매칭은 근사 분석이다.
- 동적 변경 감지는 완전하지 않다. 프로젝트 전체에서 감지된 메서드 변경은 실행 순서에
  관계없이 보수적으로 적용되므로, 변경 전 저장한 메서드 별칭도 누락될 수 있다.
- 가변 컨테이너를 변경한 뒤의 정확한 원소 값 대신 UNKNOWN을 사용한다.
  임의 인덱스·slice·동적 키·사용자 정의 컨테이너는 일반적으로 추론하지 않는다.
